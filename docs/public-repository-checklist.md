# Public-repository safety checklist

Before publishing this project:

- [ ] Confirm `.env` is absent and only `.env.example` is tracked.
- [ ] Confirm database passwords, API keys, tokens, and private URLs are absent.
- [ ] Confirm PostgreSQL data volumes and database dumps are absent.
- [ ] Confirm generated bytecode, test caches, build output, and virtual
      environments are absent.
- [ ] Confirm sample exports contain synthetic values only.
- [ ] Confirm logs do not contain connection strings or credentials.
- [ ] Confirm documentation does not include user-specific local paths.
- [ ] Run a case-insensitive search for `password`, `secret`, `token`, and
      `api_key`, then inspect every match.
- [ ] Run the test, lint, compilation, and migration checks.

The repository's `.gitignore` excludes local environment files, PostgreSQL
volumes, caches, bytecode, build output, and package metadata. A human review
is still required before publication.
