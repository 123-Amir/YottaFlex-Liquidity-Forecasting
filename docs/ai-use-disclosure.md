# AI-use disclosure

## Use of AI assistance

AI assistance was used during implementation as a coding and review aid. It
helped with:

- translating the written requirements into phased implementation tasks;
- drafting and revising SQLAlchemy models, migrations, services, tests, and
  documentation;
- identifying defects through test output and database verification;
- reviewing deterministic generation, reconciliation, scenario isolation, and
  API behavior.

## Human responsibility

The project owner remains responsible for:

- deciding the requested scope and phase boundaries;
- reviewing generated code and documentation;
- approving changes before moving to the next phase;
- running and interpreting the database, API, and acceptance checks;
- protecting credentials and confirming that published artifacts contain only
  synthetic data.

AI-generated suggestions were not treated as evidence of correctness. Claims
in this repository are supported by executable tests, migration checks,
database queries, or explicitly labelled benchmark results.

## Data and privacy

The generator creates synthetic records. No production customer, employee, or
bank data is required. Local `.env` files, PostgreSQL volumes, caches, and
generated bytecode must remain uncommitted.
